## 原生 GUI 实测

使用实际打包应用的辅助功能树及窗口截图验证：

1. 豆瓣四分类入口、烂番茄三个分类入口、来源说明与原网页链接；烂番茄实际海报及新鲜度显示正常。
2. 最近播放为自适应卡片；显示海报 / 占位图、完整片名区域、上次集数和时间。
3. 「猫与龙」卡片内滚动改变内部选集位置，外层页面位置不变；当前集带「上次」标记。
4. 批量管理 → 全选 7 条 → 删除所选 → 显示 7 条删除确认 → **取消**。7 条原始历史全部保留；退出管理后选集按钮恢复可用。
5. 「片源管理」显示运行时扩展说明、39 / 6 / 33 源能力概览与 JS 规则提示。
6. 「儿童启蒙 → 连接运行时」空地址 / 未信任时检测和保存禁用。
7. 填入本地 fixture 单源地址并信任 → 检测返回 **1 个分类、1 条内容**，同时明确提示仅检测首页，未验证搜索、插件执行或实际播放。
8. **取消连接弹窗，未把本地测试地址保存到用户源。** 最终停留在最近播放卡片页。

没有通过 GUI 删除用户历史、清空收藏或安装任何第三方插件运行时。批量删除的状态逻辑通过独立测试验证；真实资料库只验证了确认与取消流程。

## 未验证 / 不应推断

- HTTP fixture 通过不等于真实 Android / JS 插件已运行；没有验证配置剩余 33 个源逐个播放。
- 桥接不捆绑运行时，不处理验证码绕过、网盘登录、完整网页嗅探或 DRM。
- `parse=0` 响应校验不等于媒体帧解码成功，仍可能遇到上游广告 / 提示视频、过期地址及编码问题。
- 本轮没有重新声明六个 AppGet 站点永久可用；早期实际媒体验证见 `VALIDATION.md`。
- 榜单抓取是当次验证，公开网页格式、访问限制及上游内容均可能变化。
