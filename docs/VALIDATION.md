## 第三方播放：成功与失败均保留

同日多轮测试，不能只取成功一次作全源承诺：

1. 早先一碗TY媒体曾解码1920×1088、9帧、进度超过2秒；GUI HD曾显示约1小时58分时长并出现上游片头广告。**这不证明整片无广告或一直可用**。
2. 本轮显式开启 `MACTVBOX_LIVE_APPGET=1` 的测试，浏览/搜索/详情/解析后，对选中的HLS地址请求因TLS错误失败；日志保留于忽略的 `build/research/test-0.3-results.txt`，没有关闭TLS校验来强行通过。
3. 本轮GUI一碗TY的HD和TC两条记录均显示「The network connection was lost」。独立AVFoundation探针也复现，表明不只是界面选片问题。
4. 对同片其他线路分别探测：TY连接中断、RY403、LZ404、BF/HN清单HTTP200。清单200仍不当作播放成功。
5. **一碗BF线路独立解码验证通过：1920×1032，实际10帧，进度2.17秒，媒体时长7173.239秒。** 只验证了短时解码，没有看完整片，也未保证所有片段、字幕或音轨。日志为 `build/research/playback-BF-0.3.txt`。
6. 蔬菜早先有4K媒体解码，但随后某条返回「领取次数」提示视频，部分备用403。因此不把解析到视频等同于正片可看；不扫描领取码、不绕过额度。

本地H.264测试片曾实测AVPlayer画面、12秒时长、自动下一集、关闭/续播。这个结果与第三方站点可用性分开记录。
