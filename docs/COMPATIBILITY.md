## 用户配置的实际边界（2026-09-30）

`http://肥猫.net` 返回的是**一份源配置**，其中名为「肥猫」的单站只是其中之一，两者不是同一个概念。实测配置共39源，六个为 AppGet：肥猫、干饭、一碗、蔬菜、方舟、番薯。其余33个未原生适配；0.4.0 提供外部运行时映射入口，但未逐个执行或验证这些插件。详见 `RUNTIME_BRIDGE.md`。

协议已适配不等于站点在线：实测有超时、403、TLS 错误和非 JSON 响应。一碗的部分媒体已产生实际解码帧；另一轮一碗线路请求出现 TLS 失败。蔬菜某条解析曾可解码，随后却返回领取次数的提示视频，部分备用线路403。干饭在一次脚本探测失败、另一次应用请求成功。因此不提供永久的「可用源白名单」，更不以解析成功保证正片。

原生支持的 `csp_AppGet` 使用配置所给的协议密钥进行正常 API 通信，并非执行 Android JAR 或绕过用户验证。验证码检测在搜索前执行，不包含 OCR、破解或自动验证。对含「限」/「VIP」的线路显示提示；优先普通线路仅是排序，不是健康检查。

## 榜单与影片匹配

- 使用豆瓣公开 `subject_collection` 的 `movie_hot_gaia`、`tv_hot`、`tv_variety_show`、`tv_animation` 片单。四栏均提供来源链接和本次获取时间。
- 公共端点不是保证稳定的开发者 API；遇验证/非 JSON/限流明确报错。同一进程可保留上一轮结果并标注更新时间，重启无离线榜单缓存。
- 榜单返回年份、演职员与评分时用于展示。片单页用于发现，完整剧情可通过原网页查看；选定片源后展示其提供的简介。
- 搜索聚合采用规范化片名+明确年份，不删除季数和版本信息。未知年份独立分组。
- 详情里同名同年优先，同名但未知年明确待核对，不同年和近似名称折叠。绝不因第一条结果自动播放。
- 同一来源多条影片记录保留在版本菜单；不同源的集号未强行合并，避免混播不同剪辑。

烂番茄使用公开 browse 页面 JSON-LD 元数据，仅读取 Movie / TVSeries，保留页面顺序与英文原名。仅提取 Tomatometer 新鲜度（0–100%），不把观众评分或百分比冒充豆瓣十分制。三个分类独立缓存；无有效影片时显示错误，不将页面变更伪装成空榜单成功。

## 配置安全

原 HTTP 配置有两处行首 `ext"` 缺少起始引号，只对该狭窄语法错误局部修复并报告。JSONC 支持字符串外注释及尾逗号；不求值表达式或执行内容。HTTPS 失败不关闭证书验证，HTTP 明文与配置中 ext/令牌的本地明文储存需由用户知悉。

只从可信配置加载自己有权访问的资源；不承诺免费、无广告、永久可用或特定清晰度。
