## MacTVBOX 0.6.1

### 修复版本显示

- 修复 0.6.0 安装后侧栏仍显示 `0.5.2` 的问题。此前侧栏文字写死为旧版本，应用实际版本及自动更新使用的版本信息仍为 0.6.0（build 9）。
- 侧栏现直接读取应用 Info.plist 的 `CFBundleShortVersionString`，与系统「关于 MacTVBOX」及更新元数据保持一致；裸 Swift 开发运行没有版本信息时显示「开发版」。
- 新增回归检查，防止 SwiftUI 版本标签再次写死。

### 安装与更新

- 当前版本 **0.6.1（build 10）**，支持 macOS 13+，通用安装包包含 Apple Silicon / Intel 架构。
- 已安装 0.6.0 的用户可在「MacTVBOX → 检查更新…」获取修复，或等待后台自动下载后正常退出应用安装。无需清除收藏、片源或播放历史。
- 0.5.2 及更早版本仍需手动安装一次带更新器的版本。
- 更新包及订阅保留 Ed25519 签名验证。本版仍为 ad-hoc 签名，尚未通过 Apple Developer ID 签名与公证。
