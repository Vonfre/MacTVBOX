## MacTVBOX 0.6.0

原生 SwiftUI + AVKit macOS 点播客户端；支持 macOS 13 及以上。

### 下载与安装

下载 **MacTVBOX-0.6.0-universal.zip**，解压后将 `MacTVBOX.app` 拖入「应用程序」。同一个包包含 Apple Silicon（arm64）和 Intel（x86_64）可执行文件；本轮实际运行验证在 Apple Silicon 上完成，未在 Intel 实机验证。

**这是首个带自动更新的版本。0.5.2 及更早版本需要先手动安装一次 0.6.0。** 收藏、片源、播放历史仍使用原来的本地资料目录，安装时不删除。

### 新增自动更新

- 启动时及运行期间每小时自动检查 GitHub Release。
- 默认自动下载新版本，验证更新订阅和安装包的 Ed25519 签名。
- 下载完成后，在退出应用时自动安装；不强制中断当前视频。可通过「MacTVBOX → 检查更新…」主动更新。
- 「MacTVBOX → 自动更新」可以分别关闭自动检查、自动下载/安装，并查看更新状态。
- 下载或校验失败不会替换现有应用；权限不足时可能需要系统授权。

### 发布与验证

- Apple Silicon / Intel 通用包；附 `SHA256SUMS` 和签名 `appcast.xml`。
- GitHub Actions 自动测试、构建、签名并发布完整 Release。
- 隔离应用实测：发现更新 → 下载 → 校验 → 退出 → 自动替换成功；被篡改的安装包、订阅文件和降级更新均被拒绝。
- 核心 / 协议测试 64 通过、0 失败、4 跳过；7 项发布元数据测试通过；播放器和键盘 / 控制栏集成测试通过。

### 签名限制

本版应用使用 **ad-hoc 签名，尚未通过 Apple Developer ID 签名和公证**。Ed25519 更新签名用于验证更新来源与完整性，不等同于 Apple 公证。首次启动可能被 Gatekeeper 阻止；请仅在确认下载来源可信后，通过 macOS「系统设置 → 隐私与安全性」允许打开，不必关闭系统安全检查。安装到「应用程序」后运行，避免在 ZIP、只读磁盘映像或受保护的临时位置中进行更新。
