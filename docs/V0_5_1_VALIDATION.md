## GUI 验证

使用打包应用的辅助功能树与截图确认：

1. 进度条在上，播放、前后集、时间、清晰度、倍速、选集、音量、设置、影院和全屏在同一行；不再有常驻右侧栏。
2. 底栏全屏按钮进入**同一主窗口的系统全屏**，应用侧栏消失，按钮变为退出全屏。
3. 全屏播放闲置后，标题与整条控制栏从画面和辅助功能树中消失，只显示视频。按空格暂停后控制栏重新出现，显示已暂停。
4. 最终版设置浮层位于视频内部，不生成系统 popover / 独立播放窗口；普通窗口及全屏截图均完整显示，长内容可在浮层内滚动。
5. 全屏下 Esc 先关闭设置浮层，仍保持全屏；再次 Esc 退出全屏，侧栏恢复。
6. 最终面板布局用本地 640 × 360 合成视频复核，未修改用户影片的片头片尾参数。

鼠标移动恢复的实现使用限定到宿主窗口的 AppKit 本地事件监听；自动计时与恢复逻辑有状态测试。本轮 GUI 实测恢复操作为空格键，不将其表述为完整鼠标轨迹测试。双击全屏入口复用同一个全屏方法，但未另行 GUI 自动化双击测试。

## 保留边界

- 仅调整 UI / 全屏交互，不改变源适配或 AVPlayer 解码能力。
- 清晰度仍是实际 HLS 档位的上限，不强制锁定码率。
- 不提供参考图中尚未实现的字幕、画中画、弹幕或进度悬停缩略图假按钮。
- 普通窗口常显；全屏暂停、缓冲、打开浮层、拖动进度或悬停控制区时保持显示；正常播放闲置约 3 秒后淡出。
