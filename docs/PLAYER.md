# 播放器 · 0.5.1

## 播放页面与控制栏

影片直接在主窗口内播放，不创建独立播放器 NSWindow。画面使用 `AVPlayerLayer`，不使用系统 `AVPlayerView` 悬浮控件。

- 进度条在底部上方，所有主要控制按钮在同一行：播放 / 暂停、上一集、下一集、已播 / 总时长、清晰度、0.5–3× 倍速、选集、音量、设置、影院、全屏。
- 选集、线路、片头片尾与音量等从底栏打开**播放器内部浮层**，不用时不占画面空间。点击关闭、画面空白处或 Esc 收起。
- 前后跳转 10 秒使用 `⌘←` / `⌘→` 或菜单栏「播放」。空格播放 / 暂停，文本输入时保留正常编辑。
- 单击画面播放 / 暂停，双击切换全屏；有浮层时单击画面只关闭浮层，不误触播放。
- 返回媒体库会暂停；侧栏「正在播放」回到同一播放器，不自动恢复播放。

## 全屏与延时隐藏

底栏最右侧直接进入 / 退出主窗口全屏，也可双击画面。全屏时媒体库侧栏收起；退出恢复原来的普通 / 影院布局。影院模式只在普通窗口中隐藏侧栏，不切换系统全屏。

全屏**正在播放**时，约 **3 秒**无操作，顶部标题和底栏以 0.25 秒淡出；移动鼠标或按键重新显示。以下情况保持显示：暂停 / 结束 / 缓冲、拖动进度、打开浮层、鼠标停在标题或控制区。关闭浮层或离开控制区后重新计时。Esc 优先关闭面板，再次按退出全屏。

事件监听只针对播放器所属窗口；离开页面移除监听并取消计时。全屏按钮操作此所属窗口，不依赖可能指向其他窗口的 `NSApp.keyWindow`。

底层仍是系统 AVPlayer。自定义界面不等于 mpv / VLC 解码引擎，也不解除媒体编码、TLS、鉴权或片源限制。暂未实现画中画、字幕 / 音轨选择、AirPlay、进度悬停缩略图或弹幕；参考图中的这些入口不会作为无效按钮放入界面。

## 片头与片尾

按 **来源 + 影片 ID** 保存到本机偏好设置，同一影片的后续剧集沿用，不影响其他影片。

- 可直接输入秒数，或每次增减 5 秒，范围 0–900 秒。0 为关闭。
- 可将当前进度标为片头结束；也可根据总时长，把当前位置标为片尾开始。
- 片头在下次开播 / 重播生效。若续播位置已经超过片头，保留该位置。
- 片尾在播放到「总时长 − 片尾秒数」时生效：开启自动下一集则继续下一集，否则暂停。最后一集结束，不循环。
- 重新播放已结束或停在片尾的影片，会回到片头跳过点。
- 未知总时长不执行自动片尾跳过；若片头 + 片尾 + 5 秒不小于总时长，则忽略跳过，以防短片被直接跳完。

片头片尾是手动时间偏移，不是 AI / 广告识别，也没有预设任何剧集的时间。

## 清晰度

读取 AVURLAsset 实际公开的 HLS variants；只有存在多个分辨率档位时才显示可选项。单档媒体或普通 MP4 不会出现虚构的 1080p / 4K 菜单。

「清晰度上限」通过 `AVPlayerItem.preferredMaximumResolution` 设置，保留自适应码率：带宽不足时仍可能选择低于上限的档位，**不是强制锁定清晰度**。选择「自动」清除限制；右侧展示当前媒体的画面尺寸。切换剧集 / 线路后重新检测，默认自动。

播放线路与清晰度不是一回事：不同线路可能是不同文件、剪辑或剧集列表。

## 状态与保存

- 在解析 / 准备期间暂停或离开页面，不会在请求完成后偷偷自动开播。
- 暂停时拖动进度、调整倍速，不会恢复播放。
- 快速换集 / 换线，旧请求、旧 item 的完成通知不会推进新影片。
- 播放进度沿用本地 `library.json`；音量、自动下一集及按影片跳过设置保存在应用 UserDefaults。
- 保留可选外部 VLC 入口，未安装时禁用。外部播放器不保证保留鉴权请求头。

## 架构参考

参考 FongMi/TV 的影片历史片头 / 片尾配置、播放设置和轨道选择的功能划分，独立实现 SwiftUI / AVFoundation 控制层。未复制其 Java / GPL 实现，没有移植 ExoPlayer 或完整 Android 播放引擎。

## 0.5.2 键盘进度控制

- 播放页面按 `←` / `→` 分别快退 / 快进 **5 秒**。按住按键沿用 macOS 的键盘重复延迟与频率，每个重复事件继续累加目标位置，释放即停止新增跳转。
- 保留 `⌘←` / `⌘→` 的 10 秒快捷跳转。暂停时调整进度不会自动播放；跳转限制在视频时长范围内。
- 只监听播放器所在的活动窗口。不抢占输入框、原生控件、设置 / 选集等浮层、拖动进度、模态窗口和带修饰键的方向键。
- 全屏隐藏控制栏后，方向键跳转会重新显示进度条，并沿用原来的自动隐藏逻辑。

## 应用图标

生成的原始图像保存在 `Resources/AppIcon/AppIcon.png`，设计提示词同目录留存。运行 `./scripts/build-icon.sh` 可重新输出多尺寸 `Resources/AppIcon.icns`；`./scripts/build-app.sh` 自动复制到应用资源目录并签名。打包使用已保存资产，不需要网络或图像 API 凭据。
