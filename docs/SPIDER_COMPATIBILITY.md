## 新增入口的边界

- Jpys：旧 HTML 结构失效，按当前公开 HTTP API 实现；即便响应包含高清地址，只要 `needLogin` 或 `flag` 不明确允许访客，便不使用。样本实际解码864×648，不能冒称1080P。使用随机应用请求标识，不读取硬件ID。
- AppRJ：有失效媒体/解析器，但第二个影片样本的备用声明线路实际解码成功；不执行任意解析网页脚本。
- AppQi：首页推荐为空时使用上游返回的首个真实分类，当前能浏览、选集和播放；搜索接口实测HTTP404，不伪装为空搜索成功。可通过「片源管理 → 浏览内容」使用。
- 看球：只接入明确未锁定的公开线路；权限字段缺失也拒绝。直播可能未开赛、过期或中断；不承诺可拖动或所有赛事可看。
- 酷狗：优先展示有MV的可用入口；歌曲需要付费/登录时明确失败，不借第三方接口绕过。
- 急救/兔小贝：搜索仅覆盖已读取的专项公开目录，并非全站全文搜索；急救内容不是医疗建议。
- 兔小贝仅匹配已审计的执行器URL和ext组合，其他 JS 仍明确待适配；并未实现通用 JS 引擎。
- 正片、预告片、音乐、体育、科普、儿童内容分角色聚合，不把同名预告片/MV当作电影来源。主流程仍是先选影片、再查来源；「浏览内容」是补充目录，不会切换全局片源。

## 荐片和瓜子

- 荐片依据配置 `ext` 的 API 地址正常请求；封面域名为可选元数据，有短超时和成功/失败缓存，不把封面失败当播放失败。
- 荐片仅导出 HTTP(S) MP4/HLS等支持的媒体。FTP/P2P/网页地址不伪装成可播放剧集。
- 瓜子使用原生 CommonCrypto/Security 实现协议加密、签名和游客会话；随机应用会话标识，不读取 Mac 硬件ID。游客注册/请求会发给第三方站点，系统TLS校验保持开启。
- 瓜子会话按 API 主机复用、合并并发初始化；401/403仅刷新一次。令牌不写入剧集或用户资料库，不无限重试验证。
- 清晰度线路仅来自上游真实返回的档位；标签是提供方标注，实际分辨率以播放器解码为准，不承诺4K。
- 已在无Android进程时验证：首页、分类、搜索、详情、解码、90秒跳转、暂停、下一集与上一集。样本为《西游记》，不是全库保证。
- 原生协议会随上游变化需要维护；空地址、验证、二次解析与不支持编码如实报错。

## B站边界

- 读取订阅 `ext.json` 分类，关键词分类通过官方公开视频搜索实现；不把 Android 登录工具 / UP 主分页规则当关键词。
- 原生首页使用公开视频热门列表，教育 / MV 的分类在分类元数据中；不宣称热门首页已按儿童年龄筛选。
- 公共搜索、详情与分P；公开单文件 MP4 解析。当前请求低清 MP4，不承诺 1080P/4K、会员、DASH 音画分离或多段 FLV。
- 订阅中不同分类入口使用同一 API。聚合搜索按相同 Cookie 作用域合并请求，再将结果归属回每个来源，避免同一搜索重复发送 6 次。桥接源、不同 Cookie 不合并。
- 可使用配置中的内联 Cookie；不自动下载远程 Cookie 文件，不把 API Cookie 转发给分类主机 / 媒体 CDN，不在剧集解析信息里存 Cookie。
- **本轮出现过 HTTP 412 风控**，即使先前搜索成功，下一次也可能被拒绝。状态码、限流与登录限制会明确提示；不自动重试轰炸或绕过。
- 分类文件读取失败时，仅回退到公开课 / 纪录片两个关键词分类，不伪造原分类；搜索和详情不依赖分类文件。

## 动漫84边界

- 固定站点协议，检查影片/剧集 ID、同站剧集路径；按数字升序整理剧集，避免网页倒序导致“下一集”播上一集。
- 从播放页识别已知 `hhjx.hhplayer.com` 解析器，只读取 JSON bootstrap 并按站点 HTTP 协议 POST；不执行网页、广告或任意 iframe 脚本。
- 仅接受受支持的 MP4/HLS 等直链。新解析器、二次解析、验证码、站点改版会明确报错，不能算可播放。
- Cookie 不转发；媒体 Referer 不包含解析器临时 key。

## 检测和故障分类

「片源管理」增加原生 / HTTP / 网盘 / JS / 待原生适配 / 工具分类，以及已适配源的「检测接入」：

1. 首页 / 分类响应；
2. 搜索（用户填写关键词时）；
3. 第一条结果的详情；
4. 第一条线路第一集的媒体地址解析。

检测不自动播放，不下载完整视频；结果中明确标注未验证实际播放。界面可以停止检测，关闭面板会取消任务，旧结果不会覆盖新一轮检测。
